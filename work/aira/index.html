Overview

Aira is a memory and context layer for AI tools. It organizes information into user-controlled records so an assistant can retrieve relevant context without treating raw conversation history as canonical memory.

The Challenge

AI tools often repeat questions or lose important decisions between sessions. A useful memory system needs to preserve provenance, handle changed or superseded facts, respect privacy boundaries, and fit relevant context into a limited token budget.

My contribution

01

Designed a provider-independent core with REST, MCP and hooks as integration surfaces.

02

Implemented typed, scoped and versioned memory records with provenance, confidence, supersession and an auditable lifecycle.

03

Kept raw conversations separate from canonical memory and filtered disallowed scopes before retrieval.

04

Built a retrieval pipeline combining SQLite FTS5 and vector search, with candidate fusion, ranking, diversification and token-budgeted context assembly.

05

Added explicit grants, private sessions and reviewable context-injection logs.

Decisions & outcome

Prioritizes portable memory and inspectable context first; broader integrations and sync are staged behind the core privacy and retrieval model.
