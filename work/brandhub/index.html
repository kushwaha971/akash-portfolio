Overview

At The Branding Club, I work as a Software Engineer II on Brandhub, a production B2B SaaS platform serving more than 8,000 brands. My work connects Next.js and TypeScript interfaces with Python/Django services and PostgreSQL, alongside AI features that help users get answers from their business data.

The Challenge

Orders, billing, stock and finance depend on the same business records, so a change in one workflow can affect several others. My work is to make these flows clear and reliable, integrate their APIs, and give the LLM assistant relevant company context without exposing records outside the user’s access.

My contribution

01

Build and maintain ordering, billing, finance and customer-portal features, working from requirements through implementation, debugging and release.

02

Develop Next.js, React and TypeScript interfaces with reusable components, forms, tables and Redux state. Handle loading, validation and API failures within each workflow.

03

Work across Python/Django REST APIs and PostgreSQL-backed services, including data integration, authentication and role-based access.

04

Built an LLM assistant for questions about company data. RAG and vector retrieval bring relevant context into the request so answers can use business records.

05

Integrate OpenAI and Gemini APIs and work on prompts, context handling and agentic workflows, with review points for generated output.

06

Contributed to AI-assisted content workflows that reduced manual content effort by 70% as a team outcome.

07

Improved page-load time by 50% and achieved Lighthouse scores above 90 through frontend performance work.

08

Collaborate with designers, backend engineers and business stakeholders, review changes and use AI coding tools to support implementation and debugging.

Decisions & outcome

For the assistant, the important boundary is which data can enter the prompt and what the user can act on afterward. For application features, I focus on clear state, reusable components and predictable API behaviour so business users can complete their work.
